# 背景介绍

不是完整的批判，只对伦理篇中的市民社会和国家观的批判

## 国内法

位置：伦理篇国家观的第一部分

外在的必然性：矛盾的说法。必然性都是内在的，外在的是偶然性。黑格尔通过矛盾辩证法说明了这一点。

马克思的批判：国家是否代表了普遍利益？（契约论：国家代表了公共利益<公益>）

黑格尔：不要人投票，由绝对精神来代表，为普鲁士君主专制作辩护

国家产生市民社会/市民社会产生政治国家（黑马的根本的对立）

道德法/抽象法的分歧都不重要，但马克思要进行社会革命，因此在市民社会/国家观问题上与黑格尔论战

马克思只承认内在必然性，不认为有外在必然性。黑格尔说的外部必然性是认为家庭和市民社会具有特殊性，国家具有普遍性，因此国家高于市民社会。国家是家庭和市民社会的内在目的。

黑格尔的三段论：国家——社会——国家（国家主义）

马克思的三段论：社会——国家——社会（共同体主义）

产生矛盾的对立与解决矛盾要靠什么方式来解决，是马克思与黑格尔的辩证法的分歧。马克思认为要回到现实世界中通过斗争来解决矛盾。

黑格尔认为：家庭是权利与义务的模糊的统一，市民社会是个人利益的战场，只有在国家中权利和义务才得到了真正统一。国家是最高阶段，是“行进在地上的神”

黑格尔：先成为公民，再成为市民。

鲍威尔兄弟的国家是政治国家，黑格尔说的国家是伦理国家，马克思沿用了青年黑格尔派的观点

总结：家庭、社会、国家之间的关系。黑格尔

马克思：当逻辑

### 一、 内部国家制度本身

论证主权和王权的同一性

每个国家涉及到主权的问题最后会归于单一的政治实体（议会，国王），如果没有这种单一性就会导致争论

君王是最后的任意的决断者（普遍性、主观性、单一性）

因此，主权的至高无上性就成为了王权的至高无上性

## 市民社会

定义：一切人反对一切人的战争

同业公会的下一阶段：官僚政治。官僚政治是国家的同业公会

四个层次：市民社会——同业公会——官僚政治——政治国家

市民社会是同业公会的唯物主义

同业公会是官僚政治的唯物主义，官僚政治是同业公会的唯灵论

单一性总想统治、规训杂多性，杂多性受自己利益与欲望的驱使要摆脱这种单一性，解决这种冲突：中项（中间等级）。黑格尔政治设计中的中项：同业公会（代表着市民，是市民选出来的）与官僚政治（代表着君王，是君王所委派的）。目的：调和市民与君王之间的矛盾和冲突
